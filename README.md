Entry for the [make.fun bounty "The One-Line Exit"](https://make.fun/c/u-kreutzx-the-one-line-exit-1dc652d1): the funniest single-line resignation letter, judged pairwise by an AI judge model.

`main.py` (Python 3.13, stdlib only) writes the line to `/output/entry.txt`:

> I hereby resign as firework safety officer, effective immediately: after three incidents, I have concluded I am the incident.

125 characters, one line, reads like a letter a person could actually send.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
